# Nikhil Rao — Portfolio

**Live site →** [nikhil-portfolio-iota-jet.vercel.app](https://nikhil-portfolio-iota-jet.vercel.app)

Blockchain / futuristic-themed personal portfolio built with **pure HTML, CSS, and vanilla JavaScript** — zero frameworks, zero build step, zero dependencies.

---

## Highlights

| Feature | Implementation |
|---|---|
| Matrix rain background | Canvas API — Katakana + math symbols |
| Terminal boot sequence | CSS keyframe staggered reveal |
| Glitch effect on name | CSS `clip-path` slice animation |
| Holographic card borders | CSS `@property` + `conic-gradient` |
| Scroll-driven animations | `animation-timeline: view()` — no JS |
| Animatable textarea | `field-sizing: content` |
| Blockchain chain timeline | Pure CSS with diamond nodes |
| Tearable project cards | SVG wavy edge + CSS transition |
| Custom cursor | Dot + lagging ring + background glow |
| Live GitHub stats | GitHub REST API — no token needed |
| Form validation | Inline error states + shake animation |

---

## Sections

- **Hero** — glitch name, typewriter role, animated stat counters
- **About** — holographic identity card with rotating conic border
- **Skills** — hover-lift tech chip grid
- **Experience** — blockchain chain with diamond nodes and block hashes
- **Projects** — tearable SVG-edged cards with metrics grid
- **GitHub Stats** — live API: profile stats, language distribution bar, 6 most recent repos
- **Education** — animated conic border card
- **Contact** — validated form with field-sizing textarea, email, LinkedIn, GitHub, X

## Deploy your own

```bash
# Clone
git clone https://github.com/OMGitsNIK/nikhil-portfolio
cd nikhil-portfolio

# Open locally
open index.html

# Deploy (Vercel CLI)
vercel --prod
```

Any `git push` to `main` auto-redeploys via the Vercel GitHub integration.
